# Galaxy Craft

StarCraft Terran command console — full-app metal HUD, scanlines, panel corners, tab swoosh.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`galaxycraft`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/galaxycraft-1.0.19.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
